# Seminararbeit: Minesweeper und Integer Programming

## Seminar

Von Sudoku zu Optimierungsmodellen:
Ganzzahlige Programme für kombinatorische Rätsel

## Thema

Modellierung und Lösung von Minesweeper-Puzzles mittels Integer Programming und FICO Xpress.

## Ziel

Ziel dieser Arbeit ist die mathematische Modellierung von Minesweeper-Puzzles sowie deren Lösung mit Hilfe von Integer Programming und dem Solver FICO Xpress.

## Fallstudien

1. Figure 1 (manuelle Modellierung)
2. Figure 2 (automatische Generierung der Nebenbedingungen)
3. Eigenes Beispiel
